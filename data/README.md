# Ingredient database

One CSV file per table. The design is described in the project's design doc; this file covers the rules.

## Tables

| File | One row is |
| --- | --- |
| `brands.csv` | A brand |
| `products.csv` | A product line (category decides which exposure routes apply) |
| `ingredient_lists.csv` | One captured label, exactly as printed, with date and URL |
| `list_items.csv` | One ingredient on one label, with its position |
| `ingredients.csv` | A distinct substance (INCI name, CAS, CI number) |
| `sources.csv` | A document: study, review, regulatory opinion, regulation, IARC monograph |
| `findings.csv` | One conclusion from one source about one ingredient, by endpoint and route |
| `regulatory_status.csv` | One rule in one jurisdiction |
| `category_routes.csv` | Which routes each product category involves (lipstick = dermal + oral) |
| `assessments.csv` | **Generated.** The rating for each ingredient and route |
| `product_summaries.csv` | **Generated.** Each product's ingredients with their ratings |

Allowed values for every coded column are in `schema.json`.

## Rating rules

Ratings are generated by `scripts/rate.py`, with no manual decisions. For each ingredient and route, the first rule that matches wins:

1. **Evidence of harm:** banned or restricted for safety in the EU, US, California or Canada; or IARC Group 1 or 2A by this route; or a regulatory or expert panel assessment, or a human study, found harm at cosmetic-level exposure.
2. **Known allergen:** listed as a cosmetic allergen by a regulator, or allergy shown in human patch-test or clinical studies (not applied to inhalation).
3. **Unclear:** harm or inconclusive results only from animal or cell studies, at doses far above cosmetic use, or from inconclusive assessments.
4. **No concerns found:** reliable studies or assessments looked and found no harm by this route, or a regulator approved the ingredient for this use (for example, an FDA color additive listing that covers lip products).
5. **No research found:** nothing reliable on record for this route.

In `product_summaries.csv`, each ingredient's `worst_rating` is the worst across the product's routes, and a route with **No research found** counts as worse than **No concerns found**. So an ingredient cleared for skin but not yet researched for swallowing shows as No research found on a lipstick, never as No concerns found.

### Quality gate

Only reliable evidence can move a rating. A study counts if it is peer-reviewed and scored **Klimisch 1 or 2** (reliable without or with restrictions, the scale used by EU and OECD chemical assessors). Regulatory opinions, regulations and IARC classifications count as authoritative. Cosmetic Ingredient Review (CIR) Expert Panel reports, published in the International Journal of Toxicology, are also treated as authoritative; the panel is funded by the cosmetics industry, which each source citation notes. A CIR conclusion is recorded only for ingredients the report's published summary names, and only for the skin route unless the report addresses swallowing. Klimisch 3 or 4 studies stay on record but are ignored by the rules.

## Run

```sh
python3 scripts/rate.py      # validate data/ and regenerate the two generated files
python3 tests/test_rate.py   # check the rules against a small fixture
```

## Ingredient labels

Labels are copied verbatim from each brand's official product page (never from Sephora), with the URL and capture date in `ingredient_lists.csv`. When a brand prints different lists per shade, each list is its own row. `scripts/import_labels.py` splits every label into `list_items.csv` and adds any new ingredients; colorants are keyed by their CI number.

```sh
cd scripts && python3 import_labels.py && cd .. && python3 scripts/rate.py
```
